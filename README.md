# Relational Database Design and SQL

Two clean PostgreSQL cases demonstrating normalization, integrity constraints, and business reporting.

## Training school

Models clients, courses, trainers, qualifications, class offerings, and enrollment. Reports cover monthly schedules, class rosters, and qualified trainers.

## Car dealership

Separates model-level attributes from individual VINs, customers, and sales. Constraints prevent duplicate sales, negative values, and invalid status values.

## Skills shown

- Third-normal-form design
- Primary, foreign, unique, and composite keys
- Check constraints and cascading relationships
- Many-to-many junction tables
- Multi-table joins, grouping, and time-window reports
- Synthetic demo records only
